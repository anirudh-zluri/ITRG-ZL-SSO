Data Analysis

Key Insight

Since April 2026 incident tickets have risen into the 50% range while root cause resolution sits at only 7.3%. Customer satisfaction remains consistently high around 4.8 to 4.9, which masks how reactive the service desk still is.
Strategic Priority

Stand up a weekly problem review that targets the top repeat incidents for permanent fixes and self-service automation. This links the rising incident share and weak root cause resolution to automation goals and fits a moderate change capacity.

Data Analysis

Key Insight

Resolution and first response times improved overall from September 2025 to August 2026, while cost per ticket fell then rose again. Speed gains are not yet stabilizing unit cost because cost rose again from June through August.
Strategic Priority

Launch a shift-left program that automates acknowledgments and portal self-service for the most common request types. This single package supports automation goals and should steady both speed and cost trends.
